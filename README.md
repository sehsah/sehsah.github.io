# Msehsah portfolio

A responsive, static portfolio for https://sehsah.github.io/.

## Edit

Update content in `index.html` and styling in `style.css`. The site uses plain HTML and CSS and needs no build step. Professional experience, skills, education and contact details are based on the supplied CV. Project descriptions are based on the public repositories. The original CV is available as a download under assets/. Project interface graphics are illustrations, not screenshots. Google Fonts are optional; system fonts are used when unavailable.

## Preview

Run `python3 -m http.server 8000` from this directory and visit http://localhost:8000.

## Publish

In GitHub repository Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**. Commits to main will update the site. Publishing from a private repository requires a GitHub plan that supports it; alternatively, the owner can make this repository public.
